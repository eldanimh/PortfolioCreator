⚙ Configurar Tokens de API

Introduce tus tokens de acceso para conectar con GitLab, GitHub y OpenAlex.

GitLab

Ve a tu instancia GitLab (gitlab.com u otra) → Avatar → Edit profile → Access Tokens

Scope necesario: read_api

Indica la URL de tu GitLab (universidad, empresa o gitlab.com). Ej: https://gitlab.tu-universidad.es. La app usará su API (/api/v4) automáticamente.

GitHub

Ve a github.com/settings/tokens → Generate new token (classic)

Scope necesario: repo o public_repo

Para buscar no se requiere Auth estricto, pero añadir una Key evitará límites.

Scope: Opcional

☁️ NVIDIA AI

Ve a build.nvidia.com → Get API Key

Modelo: gemma-2-2b-it

🧠 LM Studio Local

Abre LM Studio → Local Server → Start

Modelo sugerido: llama-3.2-3b-instruct
