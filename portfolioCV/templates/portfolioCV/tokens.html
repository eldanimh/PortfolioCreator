⚙ Configurar Tokens de API

Introduce tus tokens de acceso para conectar con GitLab URJC, GitHub y OpenAlex.

🦊 GitLab URJC

Ve a gitlab.eif.urjc.es → Avatar → Edit profile → Access Tokens

Scope necesario: read_api

🐙 GitHub

Ve a github.com/settings/tokens → Generate new token (classic)

Scope necesario: repo o public_repo

📚 OpenAlex

Para buscar no se requiere Auth estricto, pero añadir una Key evitará límites.

Scope: Opcional

🤖 Gemini AI

Ve a aistudio.google.com/apikey → Create API Key

Modelo: gemini-2.0-flash

🧠 LM Studio Local

Abre LM Studio → Local Server → Start

Modelo sugerido: google/gemma-4-e4b
